### DS Soft DB v0.2.0 (05.11.2026) ###

* **[=]** Исправлены фатальные ошибки в isTableExists(), isFieldUnique(),
            prepareValue() (yaml), processTransaction() и при ошибке подключения;
* **[=]** filterIsNull() формировал условие "i.field = ' IS NULL'" вместо IS NULL;
* **[=]** filterEqual() с NULL, filterIn() с пустым массивом и filterRelated()
            (двойное экранирование, кавычки в режиме BOOLEAN);
* **[=]** Устранена потеря разделителя AND при работе с группами filterStart()/filterEnd();
* **[=]** orderBy() больше не игнорирует сортировку по выражениям (RAND(), COUNT(*) и т.п.);
* **[=]** insertOrUpdate() учитывает $skip_check_fields и формирует корректный
            SQL при пустых данных;
* **[=]** _update() и _delete() без WHERE больше не выполняются; удаление выполняется
            через алиас и не портит строковые значения;
* **[=]** get() всегда возвращает массив и сохраняет ключ 0; getItem() учитывает
            DISTINCT/STRAIGHT_JOIN/GROUP BY; getSQL() подставляет префикс таблиц;
* **[=]** getTableFields()/getTableFieldsTypes() не падают при ошибке запроса;
            createTable() — устранён undefined index, экранирование DEFAULT,
            кодировка по умолчанию;
* **[=]** increment() и replaceFieldString() проверяют имя поля;
* **[=]** getIndex()/getTableIndexes() возвращают поля составного индекса
            в правильном порядке;
* **[=]** Драйвер MySQL: защита от работы с закрытым соединением, автопереподключение
            при ошибках 2006/2013, исправлено применение кодировки, безопасная работа
            без соединения;
* **[=]** Debug::log() не падает при отсутствии запущенного таймера;
            DBSingeltone — видимость магических методов и проверка аргументов getInstance();
